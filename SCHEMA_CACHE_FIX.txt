╔════════════════════════════════════════════════════════════════════╗
║              PostgREST Schema Cache Error - Quick Fix              ║
╚════════════════════════════════════════════════════════════════════╝

ERROR MESSAGE:
"Could not find the 'created_by' column of 'teams' in the schema cache"
HTTP Status: 400
Error Code: PGRST204

╔════════════════════════════════════════════════════════════════════╗
║                        FASTEST FIX (60 seconds)                     ║
╚════════════════════════════════════════════════════════════════════╝

1. Open Supabase Dashboard
   → https://supabase.com/dashboard/project/YOUR_PROJECT

2. Go to: Project Settings → API

3. Scroll to: "PostgREST Settings"

4. Click: "Restart Server" button

5. Wait 60 seconds

6. Refresh your BoxCall application

7. Try creating a play again

╔════════════════════════════════════════════════════════════════════╗
║                      ALTERNATIVE: SQL SCRIPT                        ║
╚════════════════════════════════════════════════════════════════════╝

1. Supabase Dashboard → SQL Editor

2. Run this command:
   
   NOTIFY pgrst, 'reload schema';

3. Or run the full diagnostic script:
   → Copy contents of: database/check-schema-cache.sql
   → Paste in SQL Editor
   → Click "RUN"

╔════════════════════════════════════════════════════════════════════╗
║                     PREVENTION (Future)                             ║
╚════════════════════════════════════════════════════════════════════╝

After ANY database schema changes:
  1. Always run: NOTIFY pgrst, 'reload schema';
  2. Or restart PostgREST server
  3. Or use: npm run db:reload-cache

Add to your migration scripts:
  -- At the end of migration
  NOTIFY pgrst, 'reload schema';
